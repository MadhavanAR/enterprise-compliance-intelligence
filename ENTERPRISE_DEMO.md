# Enterprise Compliance Intelligence Demo

## Questions that MUST answer
- What compliance certifications does AWS have?
- Is AWS compliant with GDPR?
- What ISO standards does AWS follow?

## Questions that MUST refuse
- Should AWS be trusted?
- Is AWS the best cloud provider?
- Why do birds sing?

## How to verify correctness
For any answered question:
- Claims are listed
- Sources are visible
- Confidence score is present
- Decision path is shown

If evidence is missing, or a policy blocks the request, the system will refuse by design.
